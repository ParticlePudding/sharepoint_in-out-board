# 座席表（動静表）Webアプリ

SharePoint Online のリストをデータの置き場所にして動く、**座席表つきの在席・行き先ボード**です。
フロアの見取り図の上に社員のカードを並べ、出勤・会議・出張・在宅・休暇などの状態と、行き先などの備考を全員で共有できます。

- **サーバー不要・ビルド不要**：HTML / CSS / JavaScript のファイルを SharePoint に置くだけで動きます。
- **外部への通信なし**：CDN や外部サービスを使いません。データは SharePoint のリストにだけ保存されます。
- **PC・スマホ・サイネージ**：1つの画面で、それぞれに合った表示に切り替わります。

> サンプルデータ（社員名・部署・見取り図など）はすべて架空のものです。

---

## できること

| 機能 | 内容 |
|---|---|
| 座席表 | フロアの見取り図の上に、状態の色つきカード（名前・備考・部署マーク）を表示。拡大縮小・フロア切替 |
| ステータス入力 | カードを押して状態（出勤・会議・現場・出張・在宅・退勤・休暇・午前半休・午後半休の9種類と未入力）と備考（16文字まで）を入力。よく使う備考は定型文としてワンタップで入力 |
| 予定予約 | 明日以降の予定を1件予約しておくと、当日に自動でステータスと備考へ反映 |
| リスト | 表・カード表示。検索、フロア・状態の絞り込み、列ごとの並び替え、列幅の調整 |
| 人数表 | グループ（部署など）ごとに状態別の人数を集計。グループ名を押すとメンバー一覧 |
| 一括変更・サイドリスト | 複数人のステータスをまとめて変更（PC）。座席表の横にリストを並べて表示（PC） |
| 「自分」ボタン | 端末ごとに自分を覚えておき、1タップで自分のステータス画面を開く |
| 席の割り当て | フリーアドレス向け。空席を押して座る人を選ぶ／ステータス画面で席を解除（設定で無効にもできる） |
| サイネージ | 表示用PCで全員の状態を表示し続ける。予定予約の当日反映もここで行う |

入力した内容は画面にすぐ反映され、SharePoint への保存は裏で行います（通信を待たずに次の操作ができます）。
ほかの人の画面には、1分ごとの自動更新で反映されます。

## まず試す（SharePoint なしで動かす）

URL に `?mock=1` を付けて開くと、`js/sample-data.js` の架空データで動きます（SharePoint には接続せず、入力は保存されません）。

```bash
python -m http.server 8765 --bind 127.0.0.1
```

ブラウザで <http://localhost:8765/?mock=1> を開きます。

- `?mock=1&mockdelay=2000` で、通信が毎回2秒かかる状態を再現できます。
- `?mock=1&mockfail=1` で、保存が必ず失敗する状態を再現できます。
- 保存まで本物と同じ通信で試したいときは、別プロジェクトの **SharePoint モックサーバー** を使います（[開発者ガイド](docs/開発者ガイド.md)の3章）。

## SharePoint に設置する

1. SharePoint にリスト **社員名簿** と **AppSettings** を作ります（列の一覧は[管理者ガイド](docs/管理者ガイド.md)の2章）。
2. `index.html` と `css/` `js/` `img/` `THIRD_PARTY_NOTICES.txt` を、サイトのアセット（`SiteAssets`）のフォルダに**フォルダ構成のまま**置きます。
3. `index.html` の `<script src="js/sample-data.js"></script>` の行を削除します。
4. `img/floor/` の見取り図を自分の職場のものに替え、`js/config.js` の `FLOORS` で席の位置を設定します。

詳しい手順・権限の設定・`.html` が開けない場合の対応は、[管理者ガイド](docs/管理者ガイド.md)を参照してください。

### 便利な URL

| URL の末尾 | 内容 |
|---|---|
| `?id=12` | その人のステータス画面を直接開く（本人用ブックマーク） |
| `?floor=2F` | 最初に表示するフロアを指定 |
| `?sidelist=1` | サイドリストを開いた状態で表示 |
| `?signage=1` | サイネージとして動かす |

```
├ CHANGES.md            変更履歴

```
