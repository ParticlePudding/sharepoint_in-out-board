# 座席表 データ構造

アプリが使うデータの置き場所・項目・書式・読み書きのタイミングをまとめた資料です。

---

## 1. 全体像

データは3か所に分かれています。

| 置き場所 | 内容 | 共有範囲 |
|---|---|---|
| SharePoint リスト **社員名簿** | 1人1行。名前・席・ステータス・備考・定型文・予定予約 | 全員 |
| SharePoint リスト **AppSettings** | 全員共通の設定（人数表のグループ） | 全員 |
| `js/config.js`（アプリのファイル） | フロア・席の位置・ステータスの種類・部署マークなどの固定設定 | 全員（ファイルを置き換えて変更） |
| ブラウザの localStorage | 表示の好み（並び順・絞り込み・列幅）と「自分」 | その端末・そのブラウザだけ |

```
 ┌─────────────── 社員名簿 ───────────────┐          ┌──────── AppSettings ────────┐
 │ Id (自動採番)  ◀──────────────────────────────────┤ Title = "StatsGroups"        │
 │ Title  名前                            │ memberIds │ Value = [ {id, name,         │
 │ Dept   部署 ──▶ config.js DEPT_SYMBOLS │           │            memberIds:[Id…]} ] │
 │ Seat   席番号 ──▶ config.js FLOORS[].seats          └──────────────────────────────┘
 │ Status ステータス ──▶ config.js STATUS_VIEW │
 │ Remarks 備考                          │
 │ SortNo  表示順                        │
 │ QuickNotes   よく使う備考（JSON配列）  │
 │ NextSchedule 予定予約（JSON 1件）      │
 └───────────────────────────────────────┘
```

---

## 2. 社員名簿（リスト名 `社員名簿`）

1人につき1行です。リスト名は `config.js` の `LIST_NAME` で変更できます。

| 内部名 | 画面での名前 | SharePoint の列の種類 | 必須 | 内容・ルール | 例 |
|---|---|---|---|---|---|
| `Id` | — | 自動（既定） | ○ | 行の番号。直行URL（`?id=`）・グループのメンバー指定に使う | `12` |
| `Title` | 名前 | 1行テキスト（既定） | ○ | 氏名 | `山田 太郎` |
| `Dept` | 部署 | 1行テキスト | | 部署名。`config.js` の `DEPT_SYMBOLS` と一致すると座席カードにマークが出る | `営業部` |
| `Seat` | 席番号 | 1行テキスト | | `config.js` の席番号。複数席は `", "` 区切り。空なら座席表に出ない | `1F-A01, 3F-A06` |
| `Status` | 状態 | 1行テキスト（または選択肢） | | 3章の9種類か空欄。それ以外の値は「未入力」として表示 | `出勤` |
| `Remarks` | 備考 | 1行テキスト | | 16文字以内（`NOTE_MAX`） | `第1会議室` |
| `SortNo` | No.（表示順） | 数値 | | リストの並び順。空欄は最後 | `3` |
| `QuickNotes` | よく使う備考 | **複数行テキスト（プレーンテキスト）** | | 4章の JSON 配列 | `["外出","15時戻り"]` |
| `NextSchedule` | 予定予約 | **複数行テキスト（プレーンテキスト）** | | 5章の JSON。予約がなければ空文字 | `{"date":"2026-11-10","status":"休暇","note":"有休"}` |

- `QuickNotes`・`NextSchedule` を1行テキストにすると255文字で切れ、JSON が壊れるため、必ず複数行（プレーンテキスト）にしてください。
- 列の内部名はアプリの `config.js`（`CONFIG.FIELDS`）と一致している必要があります。

### 席番号（`Seat`）の扱い
- 読むとき：全角→半角・小文字→大文字に正規化し、「,」「、」「/」空白で分割します（`app.parseSeats`）。
- 設定画面で保存するとき：正規化した席番号を `", "` でつないで保存します。
- `config.js` の `FLOORS[].seats` にない席番号は「座席表に存在しない席」として扱い、座席表には出ません（リストでは「(未登録)」と表示）。

## 3. ステータス一覧（`Status`）

`config.js` の `STATUS` / `STATUS_VIEW` / `STATUS_ORDER` で定義しています。

| 値（保存される文字） | 表示 | 色 | 並び替え順 |
|---|---|---|---|
| `出勤` | 出勤 | 緑 | 1 |
| `会議` | 会議 | 青 | 2 |
| `現場` | 現場 | 青 | 3 |
| `出張` | 出張 | オレンジ | 4 |
| `在宅` | 在宅 | オレンジ | 5 |
| `午前半休` | 午前半休 | 赤 | 6 |
| `午後半休` | 午後半休 | 赤 | 7 |
| `休暇` | 休暇 | 赤 | 8 |
| `退勤` | 退勤 | 赤 | 9 |
| （空文字） | 未入力 | 白 | 10 |

- ボタン・選択肢の並びは `STATUS_VIEW` のキー順（出勤・会議・現場・出張・在宅・退勤・休暇・午前半休・午後半休・未入力）です。
- 並び替え（リストの「状態」順）は上の表の「並び替え順」です。

## 4. よく使う備考（`QuickNotes`）

文字列の JSON 配列です。

```json
["外出中", "15時戻り", "来客対応"]
```

| ルール | 内容 |
|---|---|
| 件数 | 1人20件まで（`QUICK_NOTES_MAX`） |
| 1件の長さ | 16文字まで（備考と同じ） |
| 空・未設定 | `config.js` の `DEFAULT_QUICK_NOTES` を表示 |
| 旧形式 | カンマ区切りの文字列（`外出,15時戻り`）も読める。JSON として読めない値はカンマ区切りとして読む |
| 配列以外の JSON | `DEFAULT_QUICK_NOTES` を表示 |

---

## 5. 予定予約（`NextSchedule`）

1人1件だけの、先の日の予定です。JSON 文字列で保存します。

```json
{ "date": "2026-11-10", "status": "休暇", "note": "有休" }
```

| キー | 型 | ルール |
|---|---|---|
| `date` | 文字列 `YYYY-MM-DD` | 保存時は明日以降（日本時間） |
| `status` | 文字列 | 3章の値（空文字＝未入力も可） |
| `note` | 文字列 | 16文字まで。空文字可 |

- **予約なし**は空文字 `""` です。
- 書式が不正（JSON でない、日付の形が違う、ステータスが不正）な場合は「予約なし」として扱います。

### 予約の一生

```
利用者が予約を保存
   │  NextSchedule = {"date":"2026-11-10","status":"休暇","note":"有休"}
   ▼
当日、サイネージ（?signage=1）が全件取得したとき
   │  Status  ← "休暇"
   │  Remarks ← "有休"
   │  NextSchedule ← ""
   ▼
予約なし
```

- 日付が過ぎた予約（サイネージが止まっていた日など）は、反映せずに `NextSchedule` を空にします。
- 利用者が「予約取消」を押すと `NextSchedule` を空にします。

## 6. AppSettings（リスト名 `AppSettings`）

全員共通の設定を「1キー＝1行」で持つリストです。現在使っているキーは `StatsGroups` だけです。

| 内部名 | 種類 | 内容 |
|---|---|---|
| `Title` | 1行テキスト | 設定のキー（`StatsGroups`） |
| `Value` | **複数行テキスト（プレーンテキスト）** | 設定の値（JSON） |

### `StatsGroups`（人数表のグループ）

```json
[
  { "id": "grp_sales", "name": "営業部", "memberIds": [1, 2, 5, 12] },
  { "id": "grp_dev",   "name": "開発部", "memberIds": [3, 4, 12] }
]
```

| キー | 型 | ルール |
|---|---|---|
| `id` | 文字列 | グループの識別子（自動で付く） |
| `name` | 文字列 | グループ名。32文字まで。名前が空のグループは読み込み時に捨てる |
| `memberIds` | 数値の配列 | 社員名簿の `Id`。重複は除く。1人が複数グループに入ってよい |

- 配列の順番が人数表の行の順番です。
- 保存時に、社員名簿に存在しない `Id` は取り除きます。
- **同時編集の保護**：読み込み時の ETag を `If-Match` に付けて保存します。他の人が先に保存していると 412 になり、上書きしません。

## 7. ブラウザの localStorage（端末ごとの保存）

サーバーには送りません。ブラウザのデータを消すと初期状態に戻ります。読み込み時に値を検証し、不正な値は無視します。

| キー | 内容 |
|---|---|
| `seatmap_my_id` | 「自分」ボタンで開く社員の `Id` |
| `seatmap_current_floor` | 座席表で最後に見ていたフロア |
| `seatmap_bulk_status` | 一括変更で最後に選んだステータス |
| `seatmap_sort_key` / `seatmap_sort_order` | リストの並び替え |
| `seatmap_search_query` | リストの検索語 |
| `seatmap_list_view_mode` | リストの表示形式（`table` / `card`） |
| `seatmap_list_status_filter` | リストの状態の絞り込み（配列） |
| `seatmap_list_floors` | リストの表示フロア（配列） |
| `seatmap_list_col_widths` | リストの列幅（列名→px） |
| `seatmap_side_list_open` | サイドリストを開いているか |
| `seatmap_side_list_view_mode` | サイドリストの表示形式 |
| `seatmap_side_list_sort_key` / `seatmap_side_list_sort_order` | サイドリストの並び替え |
| `seatmap_side_list_search` | サイドリストの検索語 |
| `seatmap_side_list_status_filter` | サイドリストの状態の絞り込み |
| `seatmap_side_list_floors` | サイドリストの表示フロア |

フロアの選択値は `config.js` のフロア `id` と、席のない人用の `__UNASSIGNED__` です。

## 8. 読み書きのタイミング

### 読み込み

| 種類 | 取得する列 | タイミング |
|---|---|---|
| 全件 | 社員名簿の全列 | 起動時、更新ボタン、日付が変わったとき（一般端末は0〜30秒ずらす）、サイネージは15分ごと、保存失敗時 |
| 軽量 | `Id` `Status` `Remarks` `NextSchedule` `Seat` | 1分ごと（ステータス画面などを開いている間・タブが非表示の間は休止） |
| 予約1件 | `Id` `NextSchedule` | サイネージが予約を反映する直前 |
| グループ設定 | AppSettings の `StatsGroups` | 人数表を表示したとき（1分間はキャッシュ）、グループ設定を開いたとき |

- 社員名簿は `Id` 順に500件ずつ分けて取得します（件数が多くても欠けません）。

### 書き込み

| 操作 | 書き込む列 | 送信のしかた |
|---|---|---|
| ステータスボタン | `Status`（＋未保存の `Remarks` `NextSchedule`） | 裏で送信。ステータス画面を閉じたときに、それまでの変更とまとめて1回 |
| 備考の保存・削除 | `Remarks` | 同上 |
| 定型文の登録・削除 | `QuickNotes` | 同上 |
| 予約の保存・取消 | `NextSchedule` | 同上 |
| 一括ステータス変更 | `Status`（＋`Remarks`） | 裏で送信（同時5件まで） |
| 空席から席を割り当て | `Seat`（「移動」はその席だけにする／「追加」は今の席の後ろに足す） | 裏で送信（すぐ送る） |
| 席の割り当て解除 | `Seat`（選んだ席を除いた残り。すべて解除なら空文字） | 裏で送信。ステータス画面を閉じたときにまとめて1回 |
| 設定画面：追加 | 全列（`Status=退勤`、`QuickNotes=初期値`） | 結果を待つ |
| 設定画面：保存 | `SortNo` `Seat` `Title` `Dept` | 結果を待つ |
| 設定画面：削除 | 行を削除 | 結果を待つ |
| グループ設定の保存 | AppSettings の `Value` | 結果を待つ（ETag で競合検知） |
| サイネージの予約反映 | `Status` `Remarks` `NextSchedule` | サイネージが自動で実行 |

- 更新は SharePoint の MERGE（変えた列だけ送る）です。
- 同じ人を同時に編集した場合は、後から保存したほうが残ります（グループ設定を除く）。
